# Training-Website
A repo for the website i have done using practice from the front-end job profile for my game project.

The website is intended to act as a portfolio website displaying artwork in the *Gallery* page by showcasing artwork that appears in the game.

Market the game through the *Overview* page by showing screenshots from the game and text explaining the hooks of the game and mechanics. 

Provide development updates to players through the *Dev Logs* page and keeping players updated.
